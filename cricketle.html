How to play: Type a cricketer's name and pick from the list. Each guess reveals how close you are on seven attributes:
  • Country and Status (Active/Retired): green = exact match, red = no match.
  • IPL Team: green = same team, yellow = played IPL but for a different team, red = one (or both) never played IPL.
  • Role and Bowling style: green = exact, yellow = shares a skill (e.g. both bowl pace, or one is an all-rounder who also bats), red = unrelated.
  • Bats: green = same hand, red = different.
  • Born and Matches: green = exact, yellow = close, red = far off. Arrow shows whether the answer is higher (↑) or lower (↓) than your guess.
Daily Puzzle is the same for everyone today. Practice mode gives you a random player any time. Stuck? Use a hint — it costs one guess. Can't get it? Give up to reveal the answer.
